Packages

          
ConMon asks this page for help over its serial port: the page runs AI models and games, fetches weather, then streams the results back into the OS.

          
llmnot installed

          
Type install llm, pick a model by its letter, then load to chat. Four engines:

          
    
            
  • SmartestChild: built-in retro chatbot, instant on any device.
    • 
            
  • Transformers.js: small models (~0.3-0.6 GB) in this tab, on the GPU or CPU.
    • 
            
  • WebLLM: bigger models (0.4-3.5 GB) on your GPU, needs WebGPU.
    • 
            
  • Ollama: models on your own PC. Set OLLAMA_ORIGINS to this site's address so the page may reach it.
    • 
          

          
install llm all downloads every model at once. mp finder shows facts about each model, with live stats from Hugging Face or Ollama.

          
WebGPU: checking… · no model loaded

          
solMeteonot installed

          
Type install solMeteo, then any place name. ConMon clears the screen, flies an ASCII world map to the place and shows the weather from Open-Meteo. Later: meteo Tokyo. Type cities Italy to browse the 2,582 built-in cities.

          
doomnot installed

          
Type install doom, then doom: the real DOOM (shareware Episode 1) drawn on ConMon's text screen. Arrows move, Ctrl fires, Space opens doors, F12 (or QUIT) goes back. On a phone the game pad appears under the screen.

          
doomynot installed

          
Type install doomy, then doomy: a small DOOM-style game written in Python, run in this page by Pyodide (~10 MB download). On your PC: download doomy.py and run python doomy.py in a terminal.

What boots here?

          
    
            
  • Multiboot v1 kernels (ELF), like ConMon or most tutorial kernels built with GRUB's multiboot header. Multiboot2-only kernels won't start.
    • 
            
  • Floppy images (≤ 2.88 MB): FreeDOS, KolibriOS, bootsector games.
    • 
            
  • ISOs and disk images: small Linux distros, BSDs, old Windows. Large images take a while since they load into memory.
    • 
            
  • 32-bit x86 only: no 64-bit long mode.
    • 
          

          
Emulation by v86 (BSD-2) with SeaBIOS (LGPL). Files you load never leave your browser.
