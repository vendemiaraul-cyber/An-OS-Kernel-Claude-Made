An operating system you can boot from a link.

ConMon is a tiny 32-bit x86 OS written in C and C++. Here it runs on an emulated PC right in your browser, next to a sandbox for the YouTube Data API.

Boot ConMon in an x86 emulator and use its shell, file system and calculator. Load your own Multiboot kernel, floppy, ISO or disk image to try it too.

YouTube Test

Search YouTube, browse what's trending, read video stats and play results, through the YouTube Data API v3 with a request log for testing.

open youtube test →
C kernelGDT, IDT, PIC, timer, keyboard, VGA, serial and a heap allocator.
C++ shell22 commands, history, and a RAM disk built on a small String/Vector library.
In-browser PCv86 translates x86 to WebAssembly; nothing is uploaded anywhere.
Your own API keyYouTube search uses a key kept in your browser, or a server key where the host can run one (Netlify).
